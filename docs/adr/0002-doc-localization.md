# ADR 0002 — Локализация документации репозитория

- **Статус:** принято (2026-08-27)
- **Контекст:** документация репозитория была «кашей» по языкам — README.md и
  CONTRIBUTING.md на русском, а часть компонентных документов (deploy/, mcp/,
  desktop/, android/ARCHITECTURE) — на английском без русской версии. Единой
  конвенции не было.

## Решение

Основной язык всей документации — **русский**. У каждого документа каноничный файл —
`<имя>.md` **на русском** (именно его GitHub рендерит как homepage репозитория или
каталога). Английский — **дополнительный** слой: companion-файл `<имя>.en.md` рядом,
слово-в-слово перевод базы. Суффикс `.ru.md` не используем — русский и есть база.

Вверху каждого файла пары — строка-навигация (языковой свитчер):
- в базе: `**Русский** · [English](<имя>.en.md)`;
- в `.en.md`: `[Русский](<имя>.md) · **English**`.

**Двуязычны только «фасадные» документы** — те, что видит внешний читатель:
`README.md`, `CONTRIBUTING.md` и компонентные README (`deploy/`, `mcp/`, `desktop/`,
`android/ARCHITECTURE.md`). **Внутренние** документы (`CLAUDE.md`, `ROADMAP.md`,
`CHANGELOG.md` и компонентные CHANGELOG, ADR, `.claude/skills/`, `changelog.d/`,
`android/DND_ARCHITECTURE.md`, `apks/README.md`, брендовые README в `design/`) ведём
**только на русском**.

## Почему так

- **Совпадает со справочным центром.** Схема `<slug>.md` + `<slug>.en.md` уже
  реализована в `docs/help/` (см. [`0001-help-center.md`](0001-help-center.md)) —
  переиспользуем её, а не вводим второй формат.
- **Русский как канон отражает реальность проекта** (язык общения и большинства
  заметок — русский), но фасад открыт и для внешней аудитории.
- **Фасадный английский окупается, внутренний — нет.** Перевод живого `CHANGELOG.md`
  (тысячи строк, растёт каждый релиз), `ROADMAP.md` и скиллов раздувает объём и
  быстро протухает без пользы для внешнего читателя.

## Отвергнутые альтернативы

- **`.ru.md` + `.md`=EN** (английский как база). GitHub-homepage стал бы английским, а
  проект русскоязычный; плюс разошлось бы со справочным центром.
- **Полное двуязычие всех md.** Максимальная симметрия, но неподъёмная поддержка
  живого CHANGELOG/ROADMAP и постоянный риск рассинхрона.
- **Только английский (без русского).** Противоречит языку проекта; терялся бы
  контекст для основного автора и русскоязычных контрибьюторов.

## Следствия

- Правя фасадный документ, синхронизируем обе версии (`<имя>.md` и `<имя>.en.md`) в
  том же изменении.
- Правило продублировано в `CONTRIBUTING.md` (раздел «Документация и локализация») —
  единый практический источник для контрибьюторов.
- Изменения только в документации — это `docs:` без бампа версий компонентов.
