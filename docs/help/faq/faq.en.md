## How do I turn on the dark theme?

**Settings** → theme: “System”, “Light” or “Dark”. System follows your operating system's setting. The same place lets you pick the interface accent colour, the date and time format and the first day of the week.

## A task is in the last column but isn't counted as done

A task is made done by the board's **completing column**, and that column is set explicitly in the board settings (by default it's the rightmost one). If columns have been reordered or a new one was added on the right, check that the column you have in mind is the one marked as completing. See [Boards and tasks](/help/boards-and-tasks) for more.

## How do I invite someone into a workspace?

The workspace menu (its name at the top of the sidebar) → **Members**: type the addresses — they turn into chips — and press **Invite**. The invitation arrives as an email with a link; the role is “Member” or “Admin”. You change the role of an existing member in the same window, with a click on its pill in the row.

The invitee first sees who invites them and where, with which role, and how many projects and members the workspace has — and can **Accept invitation** or **Decline**. Invitations waiting for an answer are listed under the field: **Resend** mails it once more (with a new link — the old one stops working), and an expired or declined one has **Extend** for another week.

The **invitation link** is one shared link to the workspace with no addressee: **Create**, then **Copy** (<kbd>Ctrl</kbd>+<kbd>C</kbd>, <kbd>⌘C</kbd> on a Mac) and send it wherever you like. Its menu sets the role, the lifetime (1, 7 or 30 days) and how many people may join. The link itself is shown once, when it is created; **Reset** issues a new one and the previous one stops working at once. “Turn the link off” closes it completely.

## How do I confirm my email or change the address?

The confirmation email carries both a link and a six-digit code. The code goes into the **Check your email** screen — it opens after sign-up when the server sends email, and from **Settings → Profile → Confirm**. The code is valid for 15 minutes and allows five attempts; **Send again** becomes available after a minute.

To change the address — **Settings → Profile → Change** (or **Change email** on the code screen): a code arrives at the new address, and until you enter it you keep signing in with the old one. A confirmed account with a password is asked for the current password. After the change the old address gets a notice, and links sent there earlier stop working.

A password recovery link is valid for an hour — the **New password** screen shows how many minutes it has left.

## Is there a mobile app?

Yes, there's an Android client — the install link is in the app, and there's a download button in the interface. The app works online and can send push notifications for reminders; the web version doesn't send push.

## What is the Inbox, and how does a note differ from a document?

The [Inbox](/help/inbox) holds quick records for yourself: notes and reminders in one feed, recorded from anywhere (**N, then M**). **Documents** are for collaboration, with formatting, version history and comments. If a note is meant for colleagues or will outlive a week — it belongs in documents.

## Where did the “What's new” window go?

It's shown once after an update. You can open it again from the same place where you saw the version number — the client and server versions are shown in the bottom-right corner of the sidebar, and hovering shows the commit and the build date.

## I forgot my password

On the sign-in screen there's a “Forgot password” link: an email with a reset link will arrive. If the email doesn't come, check your spam folder.

## The app said a new version is out

That's normal: the web client notices a new release on its own and offers to reload. Nothing gets lost — accept when it suits you.
