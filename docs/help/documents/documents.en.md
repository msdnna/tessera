The **Documents** section is a collaborative editor for what doesn't fit into a task description: requirements, meeting notes, guides. The section is marked `alpha`: it's evolving, and some things still change.

![The Documents section: document cards with previews](../assets/documents-light.png)

## Structure

Documents are filed into a tree — a document can have nested documents, so the section behaves like a small wiki. On the left is the list of documents, on the right the outline of the current one, built from its headings.

## Editor

Text is typed in a block editor: headings, lists, tables, images, code blocks, alignment. A block can be dragged by the handle on the left, a new one inserted below it, and each one discussed separately.

**Comments are anchored to a block** rather than sitting in a shared list: a thread opens next to the paragraph, is marked resolved and, if needed, reopened.

## Word and PDF import

A `.docx` document is uploaded straight into the section with its formatting preserved: text colours and sizes, horizontal rules, code blocks, table fills and borders. Colours from Word stay readable in the dark theme too.

PDF files open in a viewer inside the app — no need to download them or switch to another program.

## Version history

A document has a history: you can look at earlier revisions and return to any of them. If two people edit one document at once, the app warns about the divergence and offers to resolve the conflict rather than silently overwriting someone else's text.

## Templates and links

A document you repeat often is saved as a **template** and created from it in one click. A document is linked to tasks — the link is visible from both sides and removed with the “Remove the link” button.
