The **Documents** section is a collaborative editor for what doesn't fit into a task description: requirements, meeting notes, guides. The section opens from the “Documents” item in the side menu (the “☰” on the left of the top bar).

**In the app, documents are read-only.** This is a deliberate choice, not an unfinished corner: a block editor with drag-and-drop blocks, comments on paragraphs and conflict resolution is a project of its own, and thrown together on a phone it would do more harm than good. You can read a document, find the paragraph you need and open a link from your phone; writing is done from the web version.

![The Documents section in the app](../assets/documents-mobile-light.png)

## Structure

Documents are filed into a tree — a document can have nested ones, so the section behaves like a small wiki. On a phone the list is shown first, and a tap on a document slides a **reader out over it**; the “‹” button at the top left returns to the list, as does the system “Back”.

## What you see when reading

Text is shown with full formatting: headings, lists, tables, images, code blocks, alignment. A document imported from Word reads with its own colours and borders — including in the dark theme.

## What's only done in the web version

- Editing the text and structure of a document.
- Comments on blocks.
- Importing `.docx` and viewing PDFs.
- Version history and rolling back to an earlier revision.
- Templates and linking a document to tasks.

Links created on the web are visible from a phone — on the “Relations” tab of the task screen.

## A document or a note

If a record is only for you and only for a couple of days, it's a [note](/help/notes), and from a phone you can both write and edit it. A document is for long material that others read.
