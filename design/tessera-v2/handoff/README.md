# Handoff: Tessera v2 — доска, поиск ⌘K, модалка задачи, Гант, стартовый экран

## Обзор
Это редизайн v2 веб-приложения Tessera (таск-трекер). Основной экран — канбан-доска. В итог вошли:
- вариант **C «Цветные дорожки»**: колонки тонированы своим цветом, сайдбар утоплен;
- сигнал приоритета — **полосой слева, как в A**;
- каскад аватаров с тултипом;
- «Создать задачу» внизу колонки и FAB быстрых действий;
- клавиатурное управление: палитра ⌘K, шпаргалка `?`, подсказки клавиш.

Затем на том же языке сделаны модалка задачи, диаграмма Ганта и стартовый экран «Мои задачи».

Главный принцип v2: **без линий-разделителей**. Блоки разделяются уровнями фона, отступами, скруглениями и тенями. 1px допустим только у фокус-кольца и у бордера тега.

## О дизайн-файлах
Файлы в `templates/board-v2/` — **дизайн-референсы в HTML** (Design Components `.dc.html`), а не продакшен-код. Задача — воспроизвести их во фронте Tessera (Vue + naive-ui), используя существующие компоненты и паттерны. Дизайн-файлы рендерят компоненты ДС (`UserAvatar`, `TagPill`, `Icon`, `TesseraIcon`, `ProjectIcon`, `BrandLogo`, `TesseraProvider`) через React-обёртки. В коде это те же Vue-компоненты, обёртки не нужны.

Чтобы открыть файлы, нужен этот проект ДС: `ds-base.js` грузит `../../_ds_bundle.js`, `_ds_bundle.css` и `styles.css`.

## Точность
**High-fidelity.** Цвета, тени, радиусы и размеры финальные. Их нужно перенести точно (см. `tokens-v2.css` и таблицы ниже). Данные и подписи — демонстрационные.

## Что нельзя ломать (из брифа)
- Группировка по тегам: колонки = теги проекта + последняя нейтральная «Без тегов». У колонки-тега нет статус-иконки и меню, её нельзя переупорядочить, нет плитки «добавить колонку».
- Порядок содержимого карточки:
  1. заголовок (до 2 строк, 14px);
  2. мета-строка: `#номер` · чип статуса · чип GitLab;
  3. пиллы: конфликт → приоритет → срок → оценка → этап → описание → теги (первый + «+N») → люди справа каскадом.
- Ховер-бар карточки: выполнить / подзадача / ещё.
- Размеры карточки: compact / medium / large.
- Шапка колонки: статус-иконка → название (600) → счётчик «5 (12)» → `Σ` оценка → шеврон → `⋯`. Свёрнутая колонка — полоса 44px. «Готово» — последняя.
- Иконки только ionicons5 outline + `TesseraIcon`. Шрифт — системный UI-стек, вебфонт не нужен. Логотип — `BrandLogo` как есть.

## Экраны

### 1. Доска (1440×900, тёмная и светлая)
Раскладка слева направо:
- рейл 56px (`--v-rail`);
- сайдбар 232px (`--v-sidebar`, на шаг темнее холста; свёрнутый — 60px);
- контент (`--v-board`).

Контент сверху вниз: топбар 52px, подбар, ряд колонок.

- **Топбар.** Слева хлебные крошки (text3 → text1). По центру поиск-триггер 420×34 (`--v-input`, радиус 8, плейсхолдер + `⌘K` в kbd). Справа: каскад участников доски (тултип со списком «На доске · N»), кнопка шпаргалки клавиш `?`, колокольчик. Кнопка «+ Задача» **убрана**.
- **Подбар** (паддинг 6px 16px 10px, контролы 34px):
  - композер-фильтр с чипами (заливка `--v-ctl`, «+» — круглая кнопка `--v-pill`);
  - чип группировки;
  - сегменты вида «Канбан / Список / Таймлайн / …»: активный сегмент `--v-card` + `--v-sh-card` + градиентная иконка;
  - действия доски.
- **Колонка** (256px, по тегам 244px, зазор 12px, паддинг 8px, радиус 18):
  - фон `color-mix(in srgb, <цвет колонки> 15%, --v-col)` в тёмной, 11% в светлой;
  - шапка 30px, паддинг слева 6px;
  - «Создать задачу» (34px, фон `--v-col`, клавиша `C`) появляется **внизу колонки при наведении**; на таче видна всегда.
- **Карточка:**
  - фон `--v-card`, тень `--v-sh-card`, радиус 14;
  - паддинги: compact 8/12, medium 10/12, large 13/14; слева +5px под полосу приоритета;
  - зазор между карточками 8px;
  - ховер: фон `--v-card-hover`, тень `--v-sh-hover`, ховер-бар сверху справа (`--v-pop`, радиус 10, `--v-sh-pop`, кнопки 26×26).
- **Приоритет:** полоса 3px.
  - Позиция: `left:6px; top:10px; bottom:10px`, радиус 3px.
  - Фон: `linear-gradient(to top, mix(c 86%, #000), c 50%, mix(c 86%, #fff))`.
  - Цвета: 0 `#9aa0aa` (полосы нет), 1 `#5b9bd5`, 2 `#3aa675`, 3 `#e0a418`, 4 `#e0533d`.
  - В пиллах флажок приоритета мягкий.
- **Каскад аватаров** (люди на карточке, участники доски, исполнители в модалке):
  - 22px, перекрытие −6px, кольцо 2px цвета подложки (`box-shadow: 0 0 0 2px var(--v-card)`);
  - до 3 аватаров + «+N» (пилла `--v-pill`).
  - Тултип по наведению (задержка 400 мс): `--v-pop`, радиус 10, `--v-sh-pop`, min-width 220px. Строки 30px: аватар 20 + имя + роль text3 («Исполнитель», «Автор»).
  - ⚠ Известный баг в макете: тултип перекрывался соседней карточкой. В коде рендерить тултип в портал (naive `NTooltip`/`NPopover` с `to="body"`), чтобы он был вне стекинг-контекста колонки.
- **FAB** «Быстрые действия»:
  - 52×52, радиус 16, отступ 20px от правого нижнего угла;
  - фон — accent-gradient, иконка «+», клавиша `N`.
  - Меню 280px (`--v-pop`, радиус 14, `--v-sh-drag`) с пунктами и клавишами второго нажатия: `T` — задача в «К работе», `R` — напоминание, `M` — заметка.
  - Подсказка у кнопки при наведении.
- **Режим тегов:** колонки `app::frontend`, `app::backend`, `design`, `bug`, «Без тегов».
  - Цвет колонки = цвет тега. В шапке — `TagPill` (двухсегментный scoped-тег), без статус-иконки и `⋯`.
  - «Без тегов» — нейтральная `#9aa0aa`.

### 4. Поиск ⌘K (палитра)
- Ширина 680px, отступ сверху 72px, радиус 16, `--v-pop`, `--v-sh-drag`, затемнение `--v-scrim`.
- Строки 48px, сгруппированы по разделам: «Задачи», «Доски и этапы», «Команды», «Люди», со счётчиками. Совпадение подсвечивается.
- Префиксы: `#` задачи, `@` люди, `>` команды.
- У выбранной строки справа подсказки `Tab действия` / `↵ открыть`. У команд — их сочетание.
- Футер 40px: `↑↓ выбрать · ↵ открыть · Tab действия · ⌘↵ в новой вкладке`, справа подсказка префиксов.
- **Tab** сужает палитру до выбранной задачи: в поле — её чип, ниже — поля с текущими значениями и клавишами:
  - «Изменить статус» (сейчас: В процессе);
  - Исполнители `A`, Приоритет `P`, Срок `D`, Теги `L`, Подзадача `⇧N`;
  - «Ещё»: Копировать ссылку `⌘⇧C`, Открыть в новой вкладке `⌘↵`.
- **Shift+Tab** — назад к результатам.

### 6. Модалка задачи (1080×800, радиус 18, `--v-pop`, `--v-sh-drag`)
- **Шапка 56px:** иконка проекта (20px, градиент проекта) → «Tessera Web» › доска › `#номер`. Справа навигация J/K и закрыть.
- **Слева — содержание:** статус и «Выполнить», заголовок, описание, подзадачи с прогрессом, активность, поле комментария (`⌘↵` — отправить).
- **Справа — утопленная панель свойств** (на шаг ниже `--v-pop`). У каждого свойства своя клавиша: статус `S`, приоритет `P`, исполнители `A` (каскад), срок `D`, теги `L`.

### 7. Гант (вид «Таймлайн»)
- Подбар тот же, что у доски; в переключателе вида активен «Таймлайн».
- Строки сгруппированы по этапам, у группы — сводная полоса. Строка задачи 36px, полоса 22–24px, радиус 7.
- Цвет полосы = цвет статуса (мягкий градиент тона). Прогресс — тонкая линия 3px внутри полосы.
- Выходные — мягкая подложка столбцов. Сегодня — подсветка колонки дня и градиентная вертикальная отметка 2px.
- У выбранной задачи — ручки по краям и подсказка `⇧←` / `⇧→` для сдвига сроков.

### 8. Стартовый экран «Мои задачи»
- **«Аврора».** Семь радиальных пятен акцентов ДС (`#7c5cff #2f80ed #0eb0a9 #18a058 #f0a020 #e0533d #eb2f96`):
  - пятна 420–560px, `blur(18px)`, расположены вверху (top −230…−280px, left −4%…80%);
  - анимации `tsAur1/2/3` по 18–27s, `ease-in-out infinite alternate`;
  - opacity `--v-aurora`: .5 в тёмной, .34 в светлой; blend: `screen` в тёмной, `normal` в светлой;
  - слой высотой 360px + высота топбара, маска `linear-gradient(to bottom, #000 0, #000 30%, transparent)`;
  - весь слой смещается за курсором: `translate(mx·46px, my·22px)`, где mx и my ∈ [−1, 1]; `transition: transform .9s cubic-bezier(.2,.8,.2,1)`.
  - Учесть `prefers-reduced-motion`: отключать анимацию и параллакс.
- **Хедер только на этом экране** — полупрозрачный, градиент продолжается под ним:
  - `position:absolute`;
  - фон `color-mix(in srgb, var(--v-board) 52%, transparent)`, в светлой 58%;
  - `backdrop-filter: saturate(1.4) blur(18px)`;
  - поле поиска `color-mix(var(--v-input) 62% / 70%, transparent)`;
  - контент получает отступ сверху на высоту хедера.
- **Приветствие:** дата 13.5px text2, «Доброе утро, Мария» 32px/700, letter-spacing −.015em. Справа сводка-пиллы 28px: «4 на сегодня», «2 просрочено» (красный тон), «1 ждёт вашего ревью» (оранжевый тон).
- **Поле быстрого ввода** разбирает строку на лету:
  - дата: сегодня / завтра / день недели; время `HH:MM`;
  - `!приоритет`: срочный / высокий / обычный / низкий или 0–4;
  - `#тег`, `@человек`.
  - Ниже — превью-чипы и заголовок без токенов.
- **Списки:** «Сегодня» и далее. Первая задача выбрана с клавиатуры, над ней подсказка клавиш.
- Мультицвет — осознанное исключение из правила «один оттенок в градиенте»: только здесь и только как фон.

## Язык градиента
У каждого не-нейтрального элемента мягкий диагональный градиент одного оттенка: темнее снизу слева, база в центре, светлее сверху справа. Кнопки, чипы, теги, аватары, метки приоритета, акцентный текст и иконки, активный таб, активный пункт сайдбара (`--v-active`). Источники — `hueGrad` / `hueGradVert` / `softFill`, `--t-accent-grad*`, `.accent-grad-text`, `<Icon gradient>` из ДС. Нейтральные серые — плоские. Разные оттенки в одном градиенте не смешиваются.

| Пиллы пунктиром / 1px | Скруглённые пиллы: пустые — иконка text3, заполненные — `--v-pill` или мягкий градиент |
| Список подзадач 1px | Трей `--v-sub`, строки с зазором 2px |

## Состояние и поведение
- **Горячие клавиши.** Глобальный менеджер с поддержкой последовательностей (`G` затем `B`, `N` затем `T`; таймаут ~1 с) и контекстов: доска, выбранная карточка, палитра, модалка. Вне полей ввода. Текст подсказок строится из того же реестра, что и обработчики.
- **Выбор карточки.** Стрелки двигают `selectedTaskId` по колонкам; выбранная карточка рисуется в состоянии «выбранная».
- **Палитра.** Состояние `query`, `scope` (`all` или задача после Tab), `activeIndex`. Префикс в начале запроса фильтрует раздел.
- **FAB.** `open`; `N` открывает, вторая клавиша выбирает пункт, `Esc` закрывает.
- **Стартовый экран.** Парсер быстрого ввода — см. `parse()` в `Home.dc.html`.
