# tessera — лоадер: спецификация

Фирменный лоадер: буква **t** с тессерой в углу → тессера вырастает и закрывает
букву → дальше бесконечно крутится, на каждом обороте разворачиваясь в один из
видов приложения.

Файлы:

| файл | что это |
|---|---|
| `loader.html` | живая референс-реализация (открыть в браузере) |
| `tessera-loader.js` | движок без зависимостей, `mountTesseraLoader(el, opts)` |
| `loader-states.json` | вся геометрия кадров + тайминги (источник истины) |

---

## Модель

Сцена — квадрат **512×512**. В ней:

1. **Глиф «t»** — путь (Fredoka 600 в кривых), `translate(-86.89, 382) scale(0.34)`.
   Управляется только прозрачностью (`t`: 1 → 0).
2. **7 плиток** (`rect`) с полями `x, y, w, h, rx, op`. Все 7 существуют всегда;
   неиспользуемые в кадре «сложены» в точку центра (`x246 y246 w20 h20 rx10 op0`).
3. Группа плиток вращается вокруг центра сцены: `rotate(rot, 256, 256)`.

Анимация = линейная интерполяция всех полей между двумя состояниями с
easing’ом `easeInOutCubic` (`cubic-bezier(0.65, 0, 0.35, 1)`).

## Состояния

| имя | смысл |
|---|---|
| `corner` | плитка в углу над «t», как на обычном логотипе (глиф виден) |
| `cover` | одна большая тессера по центру, закрывает «t» (глиф скрыт) |
| `kanban` | 2 колонки разной высоты |
| `list` | 3 строки + 3 маркера слева |
| `timeline` | вертикальная ось, 3 узла, 3 строки разной длины |
| `gantt` | 4 полосы «лестницей» |
| `matrix` | 2×2 |

Точные числа — в `loader-states.json` → `states`.

## Последовательность

**Вступление — один раз:**

| шаг | из → в | мс |
|---|---|---|
| пауза | `corner` | 800 |
| рост | `corner` → `cover` | 600 |
| пауза | `cover` | 250 |

**Цикл — бесконечно.** Для каждого вида из
`['corner', 'kanban', 'list', 'timeline', 'gantt', 'matrix']`:

| шаг | из → в | поворот | мс |
|---|---|---|---|
| разворот | `cover` → вид | 0 | 540 |
| пауза | вид | 0 | 620 |
| сворачивание | вид → `cover` | 0 | 480 |
| поворот | `cover` | 0° → 90° | 780 |

Полный цикл — 6 × 2420 = **14 520 мс**.

Поворот заканчивается на 90°, а следующий разворот снова начинается с 0° —
разрыва не видно, потому что скруглённый квадрат одинаков каждые 90°.
Первый вид в цикле (`corner`) — это символ приложения: тессера уменьшается
до угловой плитки логотипа, показывает «t» и снова разворачивается.

## Реализация

### Web
Готово в `tessera-loader.js` — SVG + `requestAnimationFrame`. Уважает
`prefers-reduced-motion: reduce` (показывает статичный кадр `kanban`).

### Android
Три варианта, по возрастанию точности:

1. **Compose** (рекомендуется) — прочитать `loader-states.json`, держать
   7 `Rect`-состояний, гонять `animateFloatAsState` / `Animatable` по
   таблице выше, рисовать через `Canvas { drawRoundRect(...) }`.
   Поворот — `rotate(deg, pivot = center)`. Глиф — `ImageVector` из
   `drawable/ic_launcher_foreground.xml` (там тот же путь «t»).
2. **Lottie** — собрать композицию по этой же таблице; 7 слоёв-прямоугольников
   с анимацией position/size/roundness + слой глифа с opacity.
3. **AnimatedVectorDrawable** — возможно, но `pathData`-морфинг требует
   одинакового числа команд; проще анимировать `translateX/Y/scaleX/scaleY`
   групп, чем `x/y/width/height`. Для 7 плиток разметка получается громоздкой —
   вариант «на крайний случай».

Цвет: белый на фиолетовом (сплеш) и `#7C6CFF` на белом (загрузка экранов).

### Проверка
Совпадение с эталоном удобно смотреть покадрово: `loader.html` рядом с
`Tessera Logo v2.html` (раздел «Лоадер») — тайминги и геометрия одинаковые.
