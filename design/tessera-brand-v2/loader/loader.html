tessera — лоадер

Референс-реализация фирменного лоадера. Вступление проигрывается один раз («t» с тессерой в углу → тессера растёт и закрывает букву), затем бесконечный цикл: тессера разворачивается в вид, сворачивается назад и медленно поворачивается на 90°. Виды: символ приложения, канбан, список, таймлайн, гант, матрица.

Подключение

<script src="tessera-loader.js"></script>
<div id="loader"></div>
<script>
  const l = mountTesseraLoader(document.getElementById('loader'), {
    size: 140,          // px
    paint: '#7c6cff',   // любой CSS-цвет или url(#gradient)
    loop: true          // false — проиграть один раз и остановиться
  });
  // l.destroy() — снять лоадер
</script>

Геометрия всех кадров и тайминги — в loader-states.json. Спецификация для нативной реализации — в README.md.
