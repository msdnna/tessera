- **fix(api): клиент не остаётся с устаревшей доской после дропа события (#2634).**
  Когда буфер медленного WS-клиента переполняется, хаб раньше молча ронял событие —
  клиент навсегда расходился с реальностью. Теперь хаб помечает такого клиента, а write
  pump шлёт маркер `resync`; фронт по нему перезагружает текущий вид. Reconnect после
  обрыва тоже теперь тянет за собой перезагрузку.
- **fix(api): фоновые воркеры не дублируют работу при перекрытии инстансов (#2633).**
  На каждом деплое старый процесс ещё тикает, пока новый поднялся — и оба гнали один и
  тот же воркер по одним строкам (двойной синк интеграции, двойная отправка уведомления,
  двойное продвижение повторяющейся задачи). Теперь тик берёт неблокирующий
  `pg_try_advisory_lock` по имени воркера: занят другим инстансом — тик пропускается.
  **Ограничение:** это закрывает единственный вредящий сценарий; полноценный
  горизонтальный режим (fan-out через LISTEN/NOTIFY, общий реестр джобов, распределённый
  rate-limit) по-прежнему не поддержан — раскладка остаётся однопроцессной.
