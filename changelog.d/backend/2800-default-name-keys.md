- **feat(api): колонки доски и личное пространство отдают ключ рядом с именем
  (#2800).** Четыре колонки новой доски и пространство, которое заводится при
  регистрации, рождались на сервере готовой русской строкой — на английском
  интерфейсе переводить их было нечем. Теперь сид пишет ещё и `name_key`
  (`todo` / `in_progress` / `review` / `done`, `personal`), а подпись рисует
  клиент из своего каталога; сохранённое русское `name` остаётся фолбэком для
  старых клиентов, поиска по БД и правил GitLab. Ключ едет и в строке задачи
  (`column_name_key` в `/workspaces/:id/tasks`), чтобы главный экран не грузил
  ради подписи всю доску. Две миграции с бэкфиллом по точному совпадению имени:
  колонка или пространство, которые пользователь уже переименовал, ключа не
  получают.
- **feat(api): переименование гасит ключ (#2800).** Колонка, названная
  «Бэклог», не должна снова становиться «To do» при переключении языка, поэтому
  `PATCH /columns/:id` и `PATCH /workspaces/:id` обнуляют `name_key`, когда имя
  действительно меняется. Повторное сохранение того же имени переименованием не
  считается — обе ручки full-replace, и правка цвета присылает имя вместе с
  ним.
- **fix(api): правила GitLab находят колонку и по ключу (#2800).** Правило
  адресует колонку по имени, а на доске, которую автор правила видит
  по-английски, русского имени он не знает. Резолв колонки теперь после
  совпадения по имени пробует ключ, причём русское дефолтное имя отображается в
  тот же ключ — оба написания приводят к одной колонке.
