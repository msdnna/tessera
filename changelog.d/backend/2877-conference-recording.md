- **feat(api): серверная запись конференций (#2864, #2877).**
  Летучку записывает не браузер участника, а сам сервер: LiveKit Egress заходит в комнату
  скрытым участником, собирает сетку и пишет mp4 в тот же том вложений
  (`rec/<конференция>/`), откуда его отдаёт наша ручка скачивания — без S3 и без копирования.
  Клиент Egress живёт в `internal/livekit` (тот же twirp-JSON, отдельный токен с грантом
  `roomRecord` — `roomAdmin` его не подразумевает), состояние — в миграции `0071`
  (`egress_id`, статус из трёх значений, ошибка, кто включил); пять маршрутов
  `POST/GET /api/conferences/:id/recording*` доступны старт/стоп только модератору, а список
  и скачивание — любому участнику пространства, потому что запись это и есть сама встреча.
  Красная точка в комнате раздаётся снапшотом `confroom`, то есть видна и тем, кто запись
  не включал. Шестой фоновый воркер закрывает то, чего не видит никто: запись кончается,
  когда из звонка вышел последний человек, — он добивает статусы брошенных egress и
  наконец удаляет файлы по `recording_ttl_days`, который с `0069` был обещанием без
  исполнителя. Запись — **опция развёртывания**: она требует Redis между SFU и egress
  (см. `deploy/README.md`), поэтому compose держит её за профилем `recording`.
