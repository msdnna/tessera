- **fix(api): синк GitLab больше не падает с «Timeout on Discussion.id / Note.id».**
  Страница issue вместе со всеми обсуждениями и комментариями упиралась в собственный
  таймаут GraphQL у GitLab, и синк повторял ту же ошибку каждую минуту. Теперь запрос
  берёт по 50 issue и при таймауте GitLab уменьшает страницу вдвое (до одной issue),
  продолжая с того же места.
- **fix(api): упавшая полная сверка GitLab больше не останавливает обычный синк.**
  Периодическая полная сверка, которая не прошла, раньше повторялась каждую минуту снова
  полной — и даже дешёвые изменения с доски GitLab не доезжали. Теперь после сбоя час
  идёт обычный (инкрементальный) синк, потом сверка пробуется снова. Сверка больше не
  запрашивает повторно issue, которые уже пришли в основном запросе.
