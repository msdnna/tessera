- **perf(api): GitLab — полная сверка в две фазы (#3105).**
  Сначала лёгкий список issue без обсуждений (страница 100, свой запомненный размер), затем
  обсуждения через `IssuesByIIDs` (пачками по 100) только для новых и изменившихся по `updatedAt`
  против снапшота ссылки; закрытые, которые политика сразу уводит в архив, — без обсуждений.
  Комментарий в GitLab двигает `updatedAt` issue (тот же факт, на котором стоит инкрементальный
  пул), поэтому неизменённые issue пропускаются без потери комментариев. Сбой второй фазы
  проваливает прогон, а не теряет комментарии.
