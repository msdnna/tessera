- **feat(api): геометрия страницы документа — импорт, экспорт и валидация (#2821).**
  Экспорт документа теперь пишет `@page` с размером листа и полями из тела
  документа — LibreOffice превращает это в `w:pgSz`/`w:pgMar`, так что альбомный
  документ выгружается альбомным. Документ без заданной геометрии выгружается
  ровно как раньше (A4, поля 20 мм), поэтому старые документы не переверстаются.
  Импорт `.docx`/`.odt`/`.fodt` читает секции (`w:sectPr`, `fo:page-*`) из самого
  файла: при конвертации в HTML геометрия теряется — LibreOffice оставляет
  `@page` только первой секции. В ответ импорта добавлены `page` (самая широкая
  секция) и `sections_differ`. Форматы без геометрии (`.doc`, `.rtf`, `.txt`)
  импортируются как раньше, без ошибки.
  Атрибут `page` разрешён только на корневом узле документа и проверяется по
  форме — шесть чисел в миллиметрах, стороны в пределах 50…2000 мм, поля
  неотрицательные и оставляющие печатную область: значение из тела документа
  попадает в CSS, который исполняет конвертер.
