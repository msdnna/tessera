- **fix(api): заголовок задачи нормализуется на сервере (#2813).**
  Создание и правка схлопывают любые пробельные последовательности (перенос
  строки, таб, двойной пробел) в один пробел и обрезают края, так что заголовок
  нельзя испортить ни из веба, ни из Android, ни из MCP. Заголовок из одних
  пробелов теперь отвергается и при создании (раньше — только при правке).
  Миграция `0068` разово чинит уже сохранённые заголовки.
