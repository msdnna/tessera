- **feat(api): импорт раскладывает разделы исходного файла по документу (#2848).**
  Раньше .docx с альбомным разделом импортировался на один лист, подобранный по
  самому широкому разделу, — с честным предупреждением, что макет сведён. Теперь
  каждая граница разделов приезжает в тело документа разрывом со своей
  геометрией: портретная часть остаётся портретной, широкая таблица — в
  альбомном разделе. Границы сопоставляются позиционно, по разрывам страницы,
  которые оставляет конвертер, — другого следа от раздела в HTML не остаётся.
  Если сопоставление неоднозначно (в разделе есть ручной разрыв страницы —
  конвертер пишет его ровно так же), поведение прежнее: один лист по самому
  широкому разделу и предупреждение. Раскладка пока только для OOXML: у ODF
  геометрия лежит в именованных макетах страниц и приходит в порядке
  объявления, а не в порядке документа, поэтому .odt импортируется по-старому.
