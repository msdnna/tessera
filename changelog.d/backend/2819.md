- **fix(api): GitLab-синк — подзадача с `S: Done` больше не уезжает в колонку родителя (#2819).**
  Дети сгруппированного issue раскладывались по колонке родителя, а собственный
  статусный лейбл ребёнка игнорировался — закрытая задача при каждом синке
  вытаскивалась из «Готово». Теперь колонка ребёнка резолвится по его же лейблам
  (без лейбла — остаётся в колонке родителя, как раньше), а признак `completed`
  считается по колонке, в которую он реально попал.
