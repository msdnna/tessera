- **perf(api): поиск по задачам и заметкам опирается на индекс (#2643).**
  `SearchTasks` и `SearchNotes` фильтруют подстрокой `ILIKE '%…%'` — ведущий шаблон,
  который не может обслужить ни один B-tree-индекс, поэтому каждый поиск сводился к
  перебору всех задач и заметок воркспейса с посимвольным сравнением по `description`
  и `body`. Добавлено расширение `pg_trgm` и четыре GIN-индекса
  (`tasks.title`/`description`, `notes.title`/`body`, миграция `0052`). Сами запросы
  не изменились — оператор остался `ILIKE`, поэтому поиск по-прежнему находит
  подстроку в любом месте текста без учёта регистра; поменялся только способ, которым
  Postgres до неё добирается. Триграммный индекс работает начиная с трёх непустых
  символов в запросе — более короткие остаются перебором.
