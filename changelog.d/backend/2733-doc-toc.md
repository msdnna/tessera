- **fix(api): экспорт документа сохраняет ссылки на его разделы (#2733).** Рендер HTML для
  конвертера теперь пишет якоря на блоки, на которые ссылаются внутренние ссылки, — без них
  `#<id>` в экспортированном docx/PDF никуда не вёл, то есть оглавление переживало экспорт
  только на вид. Якоря ставятся **отдельным проходом и только на те блоки, на которые
  действительно ссылаются**: ссылка может указывать на заголовок ниже себя по тексту, а `id`
  на каждом абзаце длинного документа — разметка, которой никто не просил, и LibreOffice
  читает её наравне с осмысленной. Идентификатор экранируется, а не берётся на веру: схема
  проверяет его как строку и не сужает до того шестнадцатеричного вида, который генерит
  редактор.
