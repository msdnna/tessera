- **fix(config): секрет из `.env.example` больше не считается заданным (#2932).**
  Проверка ловила только пустой `JWT_SECRET`, а плейсхолдер, который раздаёт
  `.env.example`, проходил молча: он длиной 43 символа, так что предупреждение
  «короче 32» не срабатывало, а `cp .env.example .env` — первый шаг установки.
  Значение лежит в репозитории, то есть им может подписать токен любой желающий.
  Теперь это приравнено к «не задан»: в production — отказ при старте, в dev —
  предупреждение. То же для `LIVEKIT_API_SECRET`, но только предупреждением:
  конференции опциональны и не должны держать инстанс лежащим.
- **fix(compose): postgres публикуется только на 127.0.0.1 (#2932).**
  Корневой `docker-compose.yml` отдавал `5432:5432`, то есть на все интерфейсы —
  вместе с дефолтным паролем из `.env.example` это открывало всю базу трекера
  любому, кто дотягивается до хоста по LAN или VPN. Порт публикуется для
  хостовых инструментов (`cmd/migrate`, тесты), а они ходят на `localhost`, так
  что привязка к петле сохраняет весь документированный сценарий. Продовый
  `deploy/docker-compose.yml` не публикует этот порт вовсе. Заодно ожил
  документированный `POSTGRES_PORT` — его не читал никто.
