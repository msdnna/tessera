- **fix(api): синк GitLab больше не стирает описание этапа (#2968).** Пул не запрашивал
  у GitLab описание этапа и при каждом проходе записывал в зеркальный этап пустую строку,
  затирая даже описание, которое Tessera сама отправила в GitLab. Теперь описание приходит
  из GitLab вместе с названием, датами и состоянием (GitLab — источник истины, пустое
  значение тоже переносится). Правка описания этапа в GitLab не меняет `updatedAt` задачи,
  поэтому её подхватывает полная синхронизация.
