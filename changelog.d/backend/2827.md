- **feat(api): узел разрыва раздела в схеме документа (#2827).**
  Тело документа может содержать `sectionBreak` — границу между двумя
  геометриями страницы. Это второй и последний узел, которому разрешён атрибут
  `page`, и проверяется он ровно по той же форме, что и у корневого узла (шесть
  чисел в миллиметрах, стороны 50…2000 мм, поля оставляют печатную область):
  значение из тела документа попадает в разметку, которую исполняет конвертер.
  Экспорт по HTML-пути пока переносит из раздела только сам разрыв страницы —
  геометрию этот путь пронести не может (LibreOffice игнорирует именованные
  `@page` при импорте HTML), она приедет вместе с рендером `.fodt`.
