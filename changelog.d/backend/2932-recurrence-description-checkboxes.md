- **fix(api): следующее повторение задачи приходило с уже отмеченными чекбоксами в описании (#2932).**
  Чекбоксы в описании — не текст: редактор рисует настоящий флажок на каждый пункт
  `- [ ] …`, а клик по нему переписывает сохранённый markdown. То есть список шагов в
  описании — тот же чек-лист, только записанный дёшево, ради рутины, на которую жалко
  заводить четыре карточки. Всё остальное «наполовину сделанное» повторение снимает
  намеренно: снимается галочка самой задачи, разотмечаются подзадачи на любой глубине,
  они же уезжают из «Готово» — и только описание ехало дословно. Со второго вхождения
  ежедневный обход приходил полностью «выполненным», и сбросить его можно было лишь
  руками правя markdown — каждый раз. Теперь при повторении флажки в описании снимаются:
  в обеих ветках правила (и «перепланировать», и «создавать копию»), у карточки и у
  каждого пункта чек-листа. Отработанная копия свои галочки сохраняет — она и есть запись
  о том, что было сделано. Образец кода внутри ``` не трогается: `- [x] …` там рисуется
  текстом без флажка, и описание, которое ДОКУМЕНТИРУЕТ чек-лист, — ровно то место, где
  такой образец живёт. Описание без флажков возвращается байт в байт.
