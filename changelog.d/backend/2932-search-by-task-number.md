- **feat(api): поиск по пространству находит задачу по её номеру (#2932).** Номер — то, чем
  задачу называют везде: «#2932» на карточке, `?task=2932` в адресе, «#№ или название» в
  поиске связей, `workspace_id` + `number` в MCP-инструментах, «#N» в строке поиска самой
  доски. Глобальный поиск был единственным местом, где он ничего не значил: `SearchTasks`
  матчил только `title ILIKE` и `description ILIKE`. Промах при этом выходил тихим, а не
  пустым — по запросу «2932» возвращались задачи, в описании которых номер УПОМЯНУТ, то
  есть правдоподобный список без той самой задачи; а глобальный поиск — единственный путь
  к карточке на доске, которую сейчас не смотришь. Теперь `#2932` и `2932` (только весь
  запрос целиком — число внутри фразы остаётся текстом) адресуют задачу, и точное
  совпадение по номеру идёт первым: упоминания всегда моложе и по `number DESC` вытесняли
  адресуемую задачу вниз, а за страницей — из ответа вовсе.
