- **fix(api): `PATCH /tasks/:id` больше не сбрасывает поля, которых нет в теле (#2642).**
  Ручка была full-replace: отсутствующее в JSON поле приезжало в обработчик нулевым
  значением и затирало сохранённое. Опаснее всего был `completed` — клиент, забывший
  его прислать, снимал отметку о выполнении, а вместе с ней `completed_at`, и попутно
  дёргал рекуррентность и переоткрытие связанного GitLab-issue. Запрос переведён на
  tri-state (отсутствует → не трогаем, `null` → очищаем, значение → ставим) поверх уже
  существующей инфраструктуры `taskPatch`/`optTime`/`optFloat`. Для клиентов, шлющих
  объект целиком (веб и Android), поведение не меняется. `title` перестал быть
  обязательным — отсутствие означает «оставить как есть», при этом явно пустой
  заголовок по-прежнему отклоняется с 400.
