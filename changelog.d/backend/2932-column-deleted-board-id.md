- **fix(api): `column.deleted` называет свою доску (#2932).** Событие уходит во весь
  воркспейс, а ехало голым `{id}` — сверить его с открытой доской было нечем, и клиенту
  приходилось на всякий случай перечитывать колонки, задачи и сам board-ряд (удалённая
  колонка уносит карточки, а `done_column_id` — FK `ON DELETE SET NULL`). Теперь
  `DeleteColumn` кладёт в пейлоад `board_id`, и работу делает только та доска, которая
  колонку потеряла. Поле добавлено, ничего не убрано — старые клиенты не ломаются.
