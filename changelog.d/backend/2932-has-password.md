- **feat(api): профиль сообщает, есть ли у аккаунта пароль (#2932).** Аккаунт,
  заведённый через GitLab, создаётся с пустым хешем («bcrypt of "" never matches»), а
  `PUT /users/me/password` сверяет текущий пароль через `CheckPassword` — то есть может
  ответить такому аккаунту только 403 «current password is incorrect». Клиенты об этом
  не знали и рисовали форму смены пароля целиком: непроходимая форма, чей отказ читается
  как «вы опечатались в текущем пароле». `provider` подставить вместо этого нельзя —
  `ResetPassword` провайдера не проверяет, значит такой аккаунт МОЖЕТ завести пароль по
  ссылке восстановления, и после этого форма ему нужна как всем. Правду знает только хеш,
  поэтому `userDTO` теперь несёт `has_password`.
