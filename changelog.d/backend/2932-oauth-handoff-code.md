- **fix(api): десктопный OAuth больше не отдаёт токены в аргументах командной строки (#2932).**
  Последний шаг входа через GitLab на десктопе — редирект на `tessera://oauth/callback#…`,
  и на Linux/Windows ОС доставляет эту ссылку, **запуская приложение с ней как с аргументом**.
  Аргументы не приватны: на Linux `/proc/<pid>/cmdline` читается любым процессом, так что
  обычный `ps aux` с чужого аккаунта на той же машине показывал 30-дневный refresh-токен
  целиком (по дороге он же оседал в логах xdg-open/портала). Теперь колбэк кладёт в ссылку
  одноразовый код (32 байта, TTL 60 с, сгорает при первом использовании), а токены выдаются
  в ответ на `POST /api/auth/oauth/handoff` уже по HTTPS. Сами токены при этом не создаются
  заранее: код хранит только идентификатор пользователя, и брошенный вход не оставляет после
  себя ни одного живого refresh-токена. Android-плечо не тронуто намеренно — там ссылка
  приходит Intent'ом, а не через argv, и смена формата выкинула бы все установленные APK
  из входа через GitLab.
