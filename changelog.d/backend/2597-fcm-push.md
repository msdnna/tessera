- **feat(notify): фоновый push на устройства через FCM (#2597).**
  Device-канал раньше был чисто эфемерным: сервер лишь помечал живое WS-событие, и
  уведомление рисовал уже открытый клиент. Теперь у такого канала может быть push-токен
  (поле `fcm_token` в том же JSONB-конфиге — ни нового типа канала, ни миграции), и
  доставка едет через обычный outbox-воркер с ретраями и backoff'ом. Правила
  роутинга, тихие часы и настройки по устройствам продолжают работать без
  перенастройки; дайджест к пушу не применяется (пуш, приехавший пачкой через полчаса,
  хуже отсутствующего). Сообщения — **data-only** (`android.priority=HIGH`), чтобы
  уведомление рисовал наш код и сохранялись deep-link в задачу и дедуп с копией,
  пришедшей по сокету. Протухший токен (FCM отвечает `UNREGISTERED`/`SENDER_ID_MISMATCH`)
  вычищается из конфига канала, сам канал остаётся включённым.
  Включается переменной **`FCM_CREDENTIALS_FILE`** (путь к JSON-ключу сервисного
  аккаунта Firebase) и по умолчанию **выключена**: без ключа сендер не регистрируется и
  device-каналы ведут себя ровно как раньше — сервер поднимается и работает без пуша.
