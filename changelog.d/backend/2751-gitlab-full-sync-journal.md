- **fix(api): полная синхронизация GitLab пропадала из журнала фоновых задач (#2751).**
  Панель «Фоновые задачи» выбрасывает завершённые синки из живого реестра и ждёт их из
  durable-журнала, но окно журнала фильтровало по времени **старта**: полный обход,
  шедший дольше окна (`JOBS_JOURNAL_TTL`, по умолчанию 1 ч), выпадал из выборки ровно
  в момент завершения — строка просто исчезала. Теперь окно и сортировка идут по
  `finished_at`. Заодно: пустой авто-прогон полного обхода больше не пропускается мимо
  журнала (скип оставлен только для инкрементальных хартбитов и пустых push-прогонов),
  а строка, создаваемая при флаше, наконец записывает `mode` — раньше авто-прогоны
  попадали в журнал с пустым режимом.
