- **fix(api): подпись группы тегов на Home больше не переезжает к чужому проекту
  (#2932).** Один и тот же префикс («s:», «effort::») может быть подписан в каждом
  проекте по-своему, а сводные экраны — Home и списки задач пространства — показывают
  одну подпись на префикс: `ListWorkspaceTagPrefixes` отдаёт объединение по всем
  проектам, хендлер оставляет ПЕРВУЮ строку каждого префикса. Кто окажется первым,
  решала сортировка — а она была только по `prefix`, то есть порядком среди одинаковых
  ключей распоряжался физический порядок строк в таблице. `SetTagPrefixes` заменяет
  набор проекта целиком (DELETE, затем вставки), поэтому переименование ЛЮБОЙ группы в
  одном проекте уносило все его строки в конец таблицы — и каждый общий с соседом
  префикс начинал показываться подписью соседа. Наблюдаемо это выглядело так: правишь в
  своём проекте подпись «prio:», а на Home сама собой переименовывается совсем другая
  группа, «effort::», причём запрос об этом ничего не говорил. Теперь ничья разрешается
  не строкой, а проектом: подпись пространства принадлежит самому старому проекту,
  который использует префикс (`ORDER BY tp.prefix, p.created_at, p.id`), и сдвинуть её
  может только переименование в этом проекте.
