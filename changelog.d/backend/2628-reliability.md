- **fix(api): graceful shutdown — деплой больше не рвёт запросы и фоновые задачи (#2629).**
  По SIGTERM/SIGINT сервер дорезает in-flight запросы, затем ждёт воркеров на границе
  тика, затем закрывает WS-хаб и только потом пул. Клиенты получают нормальный
  close-frame и переподключаются к новому процессу вместо «соединение оборвалось».
  Бюджет гашения — `GRACEFUL_TIMEOUT` (по умолчанию 20s).
- **perf(api): last_used_at у PAT пишется не чаще раза в 5 минут (#2636).**
  Раньше каждый запрос с personal access token занимал коннект пула ради одного
  `UPDATE`; пакетный клиент (MCP, CI) выедал пул апдейтами, которые никто не читает с
  секундной точностью. Интервал — `PAT_TOUCH_INTERVAL` (0 возвращает старое поведение).
