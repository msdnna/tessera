- **feat(api): вложения задачи уходят в GitLab при создании issue (#2713).**
  Картинки из описания и комментариев, а также файлы вкладки «Вложения», заливаются в
  хранилище проекта (`POST /projects/:id/uploads`), и ссылки в issue переписываются на
  выданные GitLab — раньше в issue оставались мёртвые ссылки на адрес Tessera. Файлы
  задачи уходят отдельной заметкой (в описании они стали бы вечным расхождением при
  сравнении с задачей). Залитое запоминается в `gitlab_uploads` и подставляется обратно
  при чтении, поэтому повторная правка описания ничего не перезаливает. Новый флаг
  интеграции `push_attachments` (по умолчанию включён) выключает заливку; тогда ссылка
  заменяется пометкой. Удаление файла в Tessera копию в GitLab не убирает — штатного API
  удаления загрузок у GitLab нет.
- **fix(api): ссылка `/api/uploads/…` больше не ломается при разборе тела issue (#2713).**
  Правило переписывания вложений GitLab срабатывало на хвосте `/uploads/…` внутри
  собственной ссылки Tessera и превращало её в `/api/` + прокси-URL. Заодно переписывание
  перестало трогать содержимое блоков кода.
