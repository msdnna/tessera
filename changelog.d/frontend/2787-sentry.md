- **feat(web): браузерная телеметрия через Sentry (self-hosted) (#2787).**
  Конфигурация приходит рантаймом из `GET /api/client-config` — в бандл не вшивается
  ничего, смена DSN не требует пересборки, а без DSN (Sentry не развёрнут, телеметрия
  выключена, бэкенд недоступен) SDK просто не инициализируется. События уходят на
  `POST /api/sentry-tunnel`, а не на хост из DSN: self-hosted Sentry виден только в LAN,
  плюс ad-блокеры режут запросы к хостам со словом «sentry». URL туннеля строится через
  `serverBase()` — в Tauri-десктопе фронт ходит на API кросс-origin, где корне-относительный
  путь ушёл бы в кастомный протокол, а не на бэкенд. Ошибки Vue и навигационные транзакции
  роутера включены, шум ResizeObserver отфильтрован. Инициализация не блокирует первую
  отрисовку: `main.js` монтирует приложение по готовности `bootstrap()`, как и раньше.
