- **fix(web): доска по прямой ссылке молча теряла realtime (#2721).**
  Резолв доски теперь переключает текущий workspace на тот, которому доска
  принадлежит: раньше открытая по ссылке «чужая» доска рисовалась, но все
  WS-события отбрасывались фильтром по скоупу, а участники и контекст тянулись
  из другого workspace. Заодно закрыта гонка старта — конкурентные переключения
  workspace больше не перезаписывают дерево сайдбара в порядке ответов сети.
