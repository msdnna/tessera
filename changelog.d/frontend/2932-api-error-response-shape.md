- **fix(web): отказ по скачиванию файла говорит на языке интерфейса, а «конференция
  удалена» больше не дублируется тостом (#2932).** Перехватчик `api/index.js`
  отклоняет запрос собственной ошибкой со `status`/`raw`/`offline` — без axios'ного
  `response`. Три места читали именно `e.response?.status` и потому не совпадали
  никогда: `ConferencesView.vue` и `ConferenceChat.vue` показывали тост «не найдено»
  поверх страницы, которая это и так говорит (комментарий рядом ровно про то, что
  так делать не надо), а в `DocumentsView.vue` ветки 503/422 были мёртвыми —
  локализованные строки `exportUnavailable`/`exportFailed` не показывались ни разу.
  Вторая половина: при `responseType: 'blob'` axios оставляет тело отказа блобом, так
  что `data.error` не читался ни на одном файловом маршруте (выгрузка документа,
  вложение задачи, вложение чата созвона, запись созвона) — пользователь видел
  буквально «Request failed with status code 404». Теперь перехватчик разбирает
  JSON из блоба, ветвление идёт по `e.status`, а 28 мёртвых чтений
  `e.response?.data?.error` убраны из 12 файлов, чтобы промашка не повторилась.
