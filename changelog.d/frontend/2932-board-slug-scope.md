- **fix(web): при открытии легаси-ссылки на доску передаём текущее
  пространство (#2932).** Адрес `/board/<slug>` не несёт проекта, а слаг доски
  уникален только внутри проекта — так что бэкенду нужна подсказка, о какой из
  одноимённых досок речь. `BoardView` теперь отдаёт `?workspace=` с тем
  пространством, в котором пользователь сейчас находится; без подсказки ссылка
  могла увести на одноимённую доску другого пространства.
