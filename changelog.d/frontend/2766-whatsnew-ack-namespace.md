- **fix(web): «Что нового» больше не подавляется ack-ами другого клиента (#2766).**
  Ключи прочтения релиза теперь неймспейсятся по клиенту (`whatsnew:web:<version>`):
  раньше общий `whatsnew:<version>` при независимой нумерации web и Android поднимал
  baseline одного клиента выше версий другого и прятал карточку навсегда. Старые
  «голые» ключи учитываются, но только для версий из своего списка релизов, поэтому
  история web сохраняется. Spotlight-подсказки остаются общими (их `navKey` — один и
  тот же раздел на всех клиентах).
