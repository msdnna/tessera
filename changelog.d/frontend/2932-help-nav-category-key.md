- **fix(web): непереведённая статья справки рвала свою категорию надвое (#2932).**
  Навигация справочного центра группировала статьи по ПОДПИСИ категории, хотя строитель
  индекса (`scripts/build-help-index.mjs`) сортирует их по русской категории и прямо
  формулирует контракт: «у руководства одна форма на всех языках, различаются только
  подписи». Статья без перевода — штатное состояние (читатель видит русский текст с
  пометкой, а не пустую страницу), но её русская подпись попадала в середину переведённой
  группы, и на английском «Boards» распадался на `Boards / Доски / Boards`: три заголовка
  там, где в индексе одна категория, два из них с одинаковым именем — то есть и
  одинаковый `:key` в `v-for`. Подпись теперь резолвится по категории, а не по статье
  (карта собирается по всему индексу до локализации), группы строятся по
  языконезависимому ключу `categoryKey`, а сама локализация и сборка дерева вынесены в
  чистый `utils/helpNav.js`.
