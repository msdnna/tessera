- **feat(web): единый слой форматирования дат и чисел (#2798).**
  Даты, время, числа и перечисления идут через `Intl` в одном месте
  (`utils/format.js` + композабл `useFormat`), а не через два десятка
  `toLocaleDateString('ru-RU', …)` по компонентам.
- **fix(web): настройка «Часовой пояс» наконец влияет на отрисовку дат.**
  Раньше она использовалась только как окно тишины для уведомлений, а всё
  остальное рисовалось в таймзоне браузера. Даты без времени (сроки из GitLab,
  «весь день») по-прежнему читаются в UTC и не уползают на соседний день.
- **feat(web): формат даты стал именованным пресетом** (`short`/`medium`/`long`/
  `iso`) вместо паттерна `dd.MM.yyyy`: порядок полей выбирает локаль, а для
  date-picker'ов Naive UI пресет переводится обратно в паттерн. Старые значения
  из БД конвертируются на лету, настраивать заново ничего не нужно.
