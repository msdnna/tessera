- **fix(web): отказ «неверный текущий пароль» говорит по-русски, а развилка приглашения
  больше не держится на английской строке (#2932).**
  `current password is incorrect` не знал ни один каталог ошибок, а опечатка в поле
  «текущий пароль» — единственный отказ из этого списка, до которого обычный
  пользователь доходит обычным путём. Печатается он не всплывающим сообщением,
  а **прямо в форме** (Настройки → Безопасность), так что английская строка оставалась
  на экране до следующей попытки.
  - Сентинел добавлен в `utils/errors.js` вместе с `no user with that email` — вторым
    ответом, который видят при добавлении участника по незнакомому адресу.
  - Второй добавить было нельзя, не починив развилку: `MembersModal` отличала
    «нет такого аккаунта» от прочих отказов сравнением `err.message` — то есть
    держалась на том, что строка **останется непереведённой**. Перехватчик теперь
    кладёт рядом с `status` ещё и `raw` — слово сервера, не тронутое `humanizeError`
    и не зависящее от языка интерфейса (зеркало android-овского `rawErrorText`), —
    и развилка читает его. Иначе фолбэк на приглашение молча выродился бы в тост.
