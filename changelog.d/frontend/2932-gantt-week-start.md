- **fix(web): недельные полосы Gantt/Timeline уважают «первый день недели» (#2932).**
  Настройка «Неделя начинается с» (Настройки → Локализация) уже перестраивала календарь
  срока, все пикеры дат Naive (`firstDayOfWeek`) и окно «внутри этой недели» у
  относительных дат — но шапка графика на масштабе «недели» резала полосы жёстко по
  понедельнику (`buildWeekBands`: `dt.getDay() !== 1`). У пользователя с воскресной
  неделей сетка графика расходилась с его же календарём на один день. Теперь
  `buildWeekBands` читает день разрыва из настроек — как соседний `buildMonthBands` уже
  читает из них язык месяца.
