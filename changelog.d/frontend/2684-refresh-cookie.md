- **feat(auth): в localStorage не осталось токенов (#2684).**
  Refresh-токен переехал в httpOnly-cookie (веб ходит на API same-origin, так что
  заголовок `X-Auth-Mode: cookie` включается всегда, кроме desktop), а access-токен
  теперь живёт только в памяти модуля `api/` и умирает вместе с вкладкой. После
  успешной XSS-инъекции не остаётся ни одного долгоживущего секрета.
  Сессия восстанавливается по cookie до установки роутера — иначе первый
  навигационный гвард выкидывал бы на `/login` при каждой перезагрузке.
  Гвард и админ-проверка читают стор, а не localStorage.
- **feat(auth): выход завершает сессию на сервере (#2684).**
  `logout()` дёргает `POST /auth/logout` и только потом чистит локальное
  состояние — httpOnly-cookie из JS не удалить, да и refresh-токен иначе жил бы
  ещё 30 дней. Запрос best-effort: без сети выход всё равно происходит.
- Desktop (Tauri) не затронут: он ходит на API кросс-ориджин, где host-only cookie
  не доедет, и продолжает получать refresh-токен в теле ответа.
