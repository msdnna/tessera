- **feat(web): счётчик показанных задач в composer bar (#2851).**
  Справа в строке фильтров, перед крестиком сброса — `показано: 2 (4)`: сначала
  карточки, в скобках — итог с учётом подзадач всех уровней (без подзадач скобок
  нет). Считается по отфильтрованным задачам, поэтому при группировке по тегам
  задача с двумя тегами учитывается один раз, а не дважды. Счётчик общий для всех
  раскладок (доска, список, календарь, таймлайн, гант, матрица) и на узких экранах
  скрывается.
