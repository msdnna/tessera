- **fix(web): комментарий перезагружал всю доску (#2932).**
  `task.commented` — единственное событие семейства `task.*`, которое на доске не
  меняет ничего: строка карточки не несёт ни счётчика комментариев, ни признака
  «комментарии есть». Нагрузка у события голая (`{task_id}`, без `board_id`), так
  что сверка «чужая доска» его не ловила, и каждый коммент в пространстве стоил
  всем открытым доскам перечитки списков задач. Быстрые команды из коммента
  по-прежнему доезжают своими событиями.
