- **feat(web): карточка пользователя при наведении на упоминание (#2714).**
  В описании и комментариях модалки задачи наведение на `@упоминание` показывает
  аватар, имя и `@логин` — для участников Tessera ещё почту и роль, для внешних
  аккаунтов GitLab только имя, логин и аватар. На тач-устройствах карточка
  открывается тапом. Упоминание, за которым нет ни участника Tessera, ни
  пользователя из ростера GitLab, карточку не показывает.
- **fix(web): упоминания составных имён в описании подсвечивались наполовину (#2714).**
  Описание передавало рендереру сырой список участников, без поля, по которому
  ищется совпадение, — «@Ann Lee» подсвечивалось как «@Ann». Описание и
  комментарии теперь строят список упоминаний одинаково.
