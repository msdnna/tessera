- **feat(web): захват во «Входящие» — поповер у FAB с разбором строки вместо окна «Новая заметка/напоминание» (#2972: #2996, #3038).**
  FAB → «Запись», `N M` (тип по тексту) и `N R` (напоминание) открывают поповер у кнопки
  (на телефоне — нижний лист). Строка разбирается на лету: дата или время — напоминание
  («завтра 10:00», «пт», «через 2 ч»; без времени — 09:00), иначе заметка; `/2951` или
  `/слово` — привязка к задаче (не найдена — красный чип, сохранить нельзя). Tab переключает
  тип вручную («вручную ×», дата у заметки зачёркивается), `⇧↵` раскрывает текст в
  Markdown-редакторе, `⌘↵` сохраняет из текста, `↑` в пустом поле возвращает последнюю
  запись. Новые заметки — личные. `#тег` и `@человек` разбираются, но пока не сохраняются
  (заглушка «Скоро · #3040»); сохранение без связи — заглушка #3031. Окно быстрого создания
  осталось только для задачи вне доски (`N T`).

  320–520 и запоминается; ≤1024px — поверх контента, на телефоне — полноэкранный лист)

  ленту; повторно — скрыть). Фильтры «Всё · Напоминания · Заметки · К этой доске» (1–4),
  группы «Сработало» (с «всё выполнить») · «Сегодня» (выполненное сегодня — зачёркнуто до
  полуночи) · «Позже» · «Заметки». Клавиши на выбранной записи: `↵` открыть (заметка и
  напоминание без задачи правятся на месте, с задачей — открывается задача), `E` выполнить,
  `H` отложить (меню: через час / вечером / завтра утром / в понедельник / к сроку задачи /
  своя дата словами), `T` в задачу (в «К работе» открытой доски, текст — в описание, время —
  в срок), `⇧D` в документ, `L` привязать к задаче, `⌫` удалить; выполнение, отложить и
  удаление — сразу с undo-тостом. Меню записи (⋯ / правый клик): те же действия, «Отвязать»,
  видимость заметки для пространства (только автор), «Теги и упоминания» — заглушка #3040.
