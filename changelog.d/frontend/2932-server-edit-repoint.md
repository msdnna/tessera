- **fix(web): десктоп — смена адреса активного сервера больше не оставляет приложение
  на старом хосте (#2932).** Правый клик по плитке хотбара → «Изменить» → новый URL
  перезаписывал профиль, но не перезагружал окно, хотя `switchTo`/`remove` делают это
  именно потому, что `baseURL` axios снят один раз на импорте: обычные запросы уходили
  на прежний хост, а обновление токена, OAuth-редирект и ссылки на аватары (там
  `apiBaseURL()` зовётся заново) — уже на новый. Теперь правка адреса активного профиля
  перезагружает окно, а перевод профиля на другой хост чистит его пространство имён
  сессии — как это делает удаление, иначе refresh-токен старого сервера ушёл бы новому.
