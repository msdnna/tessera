- **fix(web): Esc, закрывающий подсказку упоминаний, закрывал всю модалку (#2932).**
  Композитор гасил клавишу для себя, но не останавливал её всплытие, а Naive UI
  закрывает модальное окно по keydown на `document`. Достаточно было напечатать «@»
  и передумать: один Esc снимал список подсказок И схлопывал модалку задачи вместе
  с ненаписанным комментарием — восстановить его нечем. То же происходило с
  подсказкой `/`-команд и в полноэкранном редакторе поверх модалки. Теперь каждый
  Esc снимает ровно один слой: сначала подсказку, потом сам композитор, и лишь
  затем — окно.
