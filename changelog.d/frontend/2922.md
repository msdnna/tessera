- **fix: корректный протокол OAuth-редиректа за HTTPS-прокси (#2922).** nginx
  фронтенда перезаписывал `X-Forwarded-Proto` своим `$scheme` (это `http` на
  участке «внешний TLS-прокси → nginx»), из-за чего вход через GitLab на инстансе
  с SSL (например Caddy на `:8443`) возвращался на `http://host:8443` и падал с
  «HTTP request to an HTTPS server». Теперь nginx сохраняет схему и хост,
  выставленные внешним прокси, а на своё значение откатывается только когда
  прокси перед ним нет — одиночные развёртывания не меняются.
