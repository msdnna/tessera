- **feat(web): окно «Проект» — Общее · Теги · Этапы · Оценка (#2971: #2989, #2990, #3028, #3029).**
  Крупное окно (ярус 2) вместо поповера тегов, модалки этапов и поповера оценки проекта:
  вкладки в утопленной колонке, автосохранение, Esc по слоям, 1–4 — вкладки, ⌘, — окно
  текущего проекта; входы — меню проекта («Настройки проекта», «Этапы…»), кнопки «Теги» /
  «Этапы» доски, палитра, «Управлять тегами…» в пикерах тегов задачи и палитры. «Общее» —
  имя, адрес, иконка и цвет, группа, удаление в два шага (архив — заглушка #3005). «Теги» —
  таблица по префиксам: имя префикса правится в заголовке группы (точечная правка), клик /
  ↵ / F2 переименовывает без двойного клика, цвет — палитра у строки, число задач и
  источник (Tessera / лейбл GitLab), замок у тегов под правилом GitLab; выбор (Space,
  ⇧↑↓) → слить в самый используемый (M), перекрасить (C), удалить с undo-тостом (⌫);
  N — новый тег («префикс::имя»), / — фильтр; переключатель «Короткие префиксы» переехал
  сюда. «Этапы» — список с датами, состоянием («Запланирован» — активный со стартом
  впереди), прогрессом и номером в GitLab, новый этап строкой (N, Tab — даты), меню строки;
  GitLab-этапы только для чтения (правка с записью в GitLab — заглушка #3010). «Оценка» —
  все режимы (часы с рабочим днём и неделей, story points, футболки, своя единица,
  наследование) и настраиваемая шкала значений пикера (#3029, быстрые значения времени и
  у задачи). TagManager и MilestoneManager удалены. Тост отмены теперь поверх крупных окон,
  ⌘Z работает и в них.
