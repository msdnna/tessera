- **fix(web): свёрнутая «Без этапа» больше не сворачивает заодно «Без тегов»
  (#2932).** Сборной дорожке — той, куда падают карточки без этапа или без тегов
  из набора группировки, — доска даёт один и тот же ключ `__none__` в обеих
  группировках, а явные оверрайды сворачивания лежат в одном блобе на доску и
  смену группировки не переживают как отдельные. Пользователь сворачивал шумную
  «Без этапа» в группировке по этапам, переключался на группировку по тегам — и
  «Без тегов», обычно самая полная дорожка такой доски, встречала его узкой
  полоской, хотя он её не трогал (и наоборот). Теперь ключ оверрайда для сборной
  дорожки именуется по группировке (`utils/boardLists.js: collapseKey`), у
  настоящих дорожек ключом остаётся их id — чужие сохранённые сворачивания не
  теряются.
