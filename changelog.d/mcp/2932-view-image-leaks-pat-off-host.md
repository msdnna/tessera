- **fix(mcp): `view_image` больше не отдаёт персональный токен постороннему хосту (#2932).**
  `FetchImage` ставил `Authorization: Bearer tsra_…` на **любой** целевой адрес, включая
  абсолютный `http(s)`-URL. А рефы картинок не наши: `collectImages` выскребает их из описания
  и комментариев задачи — текста, который пишет любой участник пространства и который синк
  GitLab зеркалит из тела issue дословно. Строка `![x](https://elsewhere/p.png)` в описании
  превращала просмотр скриншотов задачи — то, для чего инструмент и существует — в передачу
  токена тому, кто эту строку написал. Токен не скоплен на пространство: это весь API от лица
  владельца. Теперь бирер уезжает только на тот бэкенд, для которого клиент настроен (сверка
  схемы и хоста с портом), а чужой URL по-прежнему скачивается, но анонимно: внешний скриншот —
  законный повод посмотреть картинку, а вот отозвать утёкший токен нельзя.
  Редиректы закрыты тем же правилом на каждом хопе (`CheckRedirect`): `net/http` снимает
  `Authorization` сам, но сравнивает **домены** и порт не смотрит — то есть переход с нашего
  хоста на другой сервис той же машины заголовок сохранял.
