- **fix(mcp): `tessera_get_task` по номеру теперь отдаёт подзадачи, теги и исполнителей (#2823).**
  Резолв по `workspace_id`+`number` бил в лёгкий by-number эндпоинт (голая строка задачи) и
  не до-загружал полную деталь по id — подзадачи не возвращались вовсе. Из-за этого stateless-агент
  ночной смены не видел, что уже разбил задачу, и плодил дубли подзадач. `resolveTaskDetail`
  делает второй фетч по id, как web/Android.

  Элемент, чей заголовок уже совпадает с живой (не архивной) подзадачей родителя, пропускается
  (`create_subtasks` → `skipped_existing`) либо отклоняется (`create_task`), если не передан
  `allow_duplicate_titles`. Сравнение по нормализованному заголовку (регистр/пробелы).
