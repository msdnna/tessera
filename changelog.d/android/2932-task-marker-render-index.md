- **fix(android): галка в превью отмечает тот пункт, по которому тапнули (#2932).**
  Клиент нёс ту же ошибку, что и веб: индекс от `RichContent` — позиция отрисованного
  `<input>` (чекбоксы рисует marked.js в WebView), а `toggleTaskMarker` считала СТРОКИ
  исходника свободной регуляркой. Списки расходились в обе стороны: `- [ ] …` внутри
  ``` или отступного кода — это пример, чекбокса для него нет, а строка считалась;
  `> - [ ] …` в цитате чекбокс даёт, но строку регулярка не видела; `- [ ]x` без пробела
  и пункт без текста GFM рисует текстом. В описании, где рядом с чек-листом лежит его же
  пример в блоке кода, тап по первому живому пункту переписывал строку ВНУТРИ блока кода,
  а сама галка отскакивала назад на ближайшей перерисовке. Теперь строки отбирает
  блок-сканер (фенсы, отступной код относительно колонки открытого пункта списка, цитаты),
  прибитый к таблице, снятой с самого marked.
