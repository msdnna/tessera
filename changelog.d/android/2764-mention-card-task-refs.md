- **feat(android): карточка упоминания и переход по «#N» (#2764).**
  Упоминание `@Имя` в описании и комментариях раньше было просто подсвеченным
  текстом, а номер задачи — обычными символами. Теперь тап по упоминанию
  открывает карточку человека (аватар, имя, почта и роль — для участников
  Tessera; логин — для пользователей GitLab), а тап по «#123» открывает эту
  задачу прямо в модалке; несуществующий номер честно говорит «Задача #123 не
  найдена». Подсветка и ссылки больше не лезут внутрь блоков кода — «#2550» в
  диффе остаётся текстом. Заодно участник со связанным GitLab-аккаунтом
  упоминается своим `@логином` (так упоминание доживает до GitLab при
  write-back), и уведомление приходит ему при любом из двух написаний.
  Паритет с вебом (#2714, #2717).
