- **fix(android): «Что нового» больше не подавляется ack-ами веба (#2766).**
  Ключи прочтения релиза теперь неймспейсятся по клиенту (`whatsnew:android:<version>`):
  раньше общий `whatsnew:<version>` при независимой нумерации давал более высоким
  версиям веба поднять baseline выше любого Android-релиза, и всплывашка не
  показывалась совсем. Старые «голые» ключи учитываются только для версий из своего
  списка релизов; spotlight-подсказки остаются общими между клиентами.
