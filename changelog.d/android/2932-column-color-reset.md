- **fix(android): цвет колонки нельзя было снять с телефона (#2932).**
  Палитра в меню колонки состояла из восьми хексов и не содержала варианта «без цвета»,
  который на вебе идёт первым (`ColumnHeader.vue`, пустая строка). Поле `color` у колонки
  необязательно, и весь мобильный экран колонку без цвета уже рисует (`parseHexColor`
  откатывается на нейтральный, градиенты выключаются по `laneHasColor`) — но отправить
  этот пустой цвет с телефона было нечем: один тап по кружку красил колонку навсегда,
  вернуть исходный вид можно было только из веб-клиента. Теперь палитра открывается
  кружком «по умолчанию» (плоский, в цвет границы) и совпадает с вебом по составу и
  порядку, а выбранным он отмечается и при `null`, и при пустой строке.
