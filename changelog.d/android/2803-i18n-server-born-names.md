- **fix(android): имена колонок и личного пространства следуют за языком профиля
  (#2803).** Эти имена рождаются на сервере — личное пространство засевается при
  регистрации, четыре колонки при создании доски, — и приезжали готовой русской
  строкой: на английском профиле доска всё равно читалась «К работе» и «На
  рассмотрении». Теперь рядом с именем едет ключ `name_key` (#2800), а подпись
  собирает `util/DefaultNames` из ресурсов читателя: канбан, список, таймлайн,
  Гант, матрица, чип статуса в модалке задачи, метка расхождения на карточке,
  композер доски, повторение в пикере срока, редактор правил GitLab, боковая
  панель со списком пространств, крошки задачи и выбор пространства в настройках
  уведомлений. Имя, которое задал пользователь, ключа не имеет — сервер гасит его
  при переименовании, — поэтому показывается как есть на любом языке: «Бэклог» не
  превращается в «To do». Незнакомый ключ (сервер новее клиента) читается
  присланной фразой, а не голым ключом. Значок ⅔-пирога у колонки «на
  рассмотрении» выбирается теперь по ключу, а не по словам в подписи, — иначе на
  английском профиле он бы пропал; у колонки без ключа опознание по имени
  осталось, как на web. Правило GitLab и привязка по-прежнему хранят серверные
  имя и id — переводится только то, что видит читатель.
