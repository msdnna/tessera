- **fix(android): настройки больше не предлагают сменить несуществующий пароль
  (#2932).** Как и в вебе: у аккаунта, вошедшего через GitLab, хеша пароля нет, и
  `PUT /users/me/password` может ответить ему только отказом «текущий пароль неверен».
  Карточка «Безопасность» теперь смотрит на новый флаг `has_password` и для такого
  аккаунта показывает объяснение и кнопку «Прислать ссылку» вместо формы. Значение по
  умолчанию у поля — `true`, чтобы профиль, закешированный сборкой постарше, не отобрал
  форму у аккаунта с паролем.
