- **fix(android): списки тегов и людей на телефоне сортировались не так, как в браузере
  (#2932).** Веб упорядочивает пользовательский текст одним коллятором —
  `Intl.Collator(lang, { numeric: true, sensitivity: 'base' })` (`utils/format.js`), и
  комментарий рядом с ним прямо называет случай «Sprint 2» перед «Sprint 10». Android
  брал `java.text.Collator` напрямую, а он про `numeric` не знает вовсе и сравнивает
  «10» с «2» посимвольно: доска, сгруппированная по неймспейсу «спринт», выдавала
  «спринт/10» раньше «спринт/2» — в браузере тот же проект показывал обратное. Ещё два
  места сортировали вообще без коллятора, по `String.lowercase()`, то есть по code unit
  UTF-16: подписи неймспейсов в чипе группировки (объявлены зеркалом веб
  `tagPrefixOptions`) и пикер исполнителей на карточке (объявлен зеркалом веб
  `pickerMembers`). Там сверх чисел ломалась «ё» — U+0451 стоит ПОЗЖЕ «я», так что тег
  «ёмкость» или коллега «Ёлкина» падали в самый низ алфавитного списка. Заведён общий
  `util/Collation.kt`: коллятор той же локали, обёрнутый так, что цепочки цифр
  сравниваются по величине. На него переведены группы тегов, подписи неймспейсов, пикер
  исполнителей и список GitLab-авторов в фильтрах.
