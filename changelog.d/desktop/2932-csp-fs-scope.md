- **fix(desktop): контент из задач больше не может выполнить код в окне приложения и
  писать в любой файл (#2932).** Окно жило с `csp: null` (политики нет вовсе) и
  `fs:scope` на `**` — т.е. любой скрипт, попавший в страницу (payload в описании
  задачи/комментарии, скомпрометированная зависимость), выполнялся и получал запись в
  произвольный файл на диске, при `withGlobalTauri: true` — вместе со всем API плагинов.
  Теперь задана CSP (`script-src 'self' 'wasm-unsafe-eval'`, `object-src 'none'`,
  `base-uri 'self'`, `form-action 'none'`; сеть/картинки/сокеты остаются открытыми —
  сервер задаёт пользователь), а бланкетный `fs:scope` убран: единственная запись
  (сохранение вложения) идёт сразу после диалога «Сохранить как», а
  `tauri-plugin-dialog` сам выдаёт доступ к выбранному пути. Обе настройки закрыты
  тестами-храповиками в `desktop/src-tauri/src/lib.rs`.
