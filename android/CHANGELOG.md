# Changelog — Tessera Android

All notable changes to the Android app. Versioned independently via
`android/VERSION`; see the repo root for backend/frontend changelogs.

## Unreleased

## 0.56.0 — 2026-07-28
- **Дерево этапов в сайдбаре** — паритет с web `ProjectRow`. У каждого проекта в
  контекстном меню появился выбор «Показывать в дереве»: Доски / Этапы / Доски и
  этапы (`tree_mode`, `PATCH /projects/:id`) плюс тумблер «Показывать закрытые этапы»
  (персистится per-project). Узлы этапов открывают доску проекта, отфильтрованную по
  этапу; узел «Бэклог» показывает задачи без этапа. Этапы грузятся лениво при
  раскрытии проекта (только когда дерево их показывает).
- **fix: кастомная SVG-иконка проекта рендерится корректно.** SVG-экспорты (draw.io)
  с CSS-функцией `light-dark()` и шрифтом `Helvetica` рисовались чёрным серифным
  текстом вместо белого. Добавлен санитайзер разметки перед Coil/AndroidSVG:
  `light-dark(a,b)` → светлый вариант, `Helvetica` → `sans-serif`, срез
  `<?xml>`/`<!DOCTYPE>`-пролога для устойчивого распознавания SVG.
- **Аватарки в фильтре «Исполнитель»** — в пикере фильтра исполнителя рядом с именем
  показывается аватар; добавлена секция GitLab-исполнителей (фильтр по
  `gl:<username>`, матчинг по `gitlab_assignees`). Паритет с web 0.136.0.
- **Аватарки и GitLab-пользователи в @-упоминаниях** — подсказки упоминаний в
  описании и комментариях показывают аватар и имя; GitLab-пользователи (без
  Tessera-аккаунта) вставляются как `@username` (GitLab резолвит при обратной записи),
  Tessera-уведомления не затрагиваются. Паритет с web 0.136.0.
- **Связывание подзадач в Ганте** — пикер связей теперь грузит подзадачи
  (`include_subtasks=1`), их можно выбрать как блокирующую связь; стрелки зависимостей
  на диаграмме Ганта рисуются к/от суб-баров подзадач. Паритет с web 0.137.0.
- **fix: мета-теги GitLab скрыты в тег-пикере.** Лейблы GitLab с правилом статуса/
  приоритета/группы (non-tag action, `match_type=prefix`) больше не появляются в
  списке добавления тегов на карточке и в фильтре. Паритет с web 0.137.1.
- **Терминология «Этап»** — лейбл скоупа под composer bar переименован «Спринт» →
  «Этап» («Этап: …», «Бэклог (без этапа)»); в настройках GitLab «Архивировать
  закрытые этапы».

## 0.55.1 — 2026-07-28
- **fix: устройство больше не дублируется при перезаходе в аккаунт.** `device_id`
  канала уведомлений теперь привязан к аппаратному `Settings.Secure.ANDROID_ID`
  (устойчив к logout/переустановке до сброса к заводским), с откатом на постоянный
  UUID, если ANDROID_ID недоступен. Раньше на некоторых устройствах id пересоздавался
  между сессиями, и бэкенд заводил новую строку-устройство на каждый вход. Уже
  зарегистрированные установки сохраняют прежний id (значение персистится).

## 0.55.0 — 2026-07-24
- **Настраиваемые биндинги обратной записи Tessera → GitLab** — паритет с web 0.135.0.
  Вместо семи фиксированных тумблеров обратной записи теперь редактор карточек-
  биндингов «действие в Tessera → действие в GitLab»: каждый биндинг задаёт триггер
  (перемещение в колонку, флаг «Выполнено», приоритет, срок, исполнители, оценка,
  этап, заголовок/описание, теги, новый комментарий) и действие на issue (установить
  метку, закрыть/открыть, поставить срок/исполнителей/оценку/этап, обновить
  заголовок/описание, синхронизировать теги, написать комментарий). Флагман — перенос
  колонки → метка статуса (`set_label`) со снятием меток того же префикса. Колонка-
  триггер матчится по стабильному id (с фолбэком на имя). Легаси-привязка без
  bindings открывается с эквивалентным редактируемым набором (синтез из старых
  тумблеров, включая разворот приоритета по правилам меток). `push_create`/
  `fetch_templates` прокидываются без изменений, чтобы не затирать веб-настроенное
  создание issue.

## 0.54.0 — 2026-07-16
- **Удаление пространства (workspace) из приложения** — паритет с web. В меню
  переключателя пространств появился красный пункт «Удалить пространство» — виден
  только владельцу (`owner_id`, сервер тоже проверяет) и только если пространств
  больше одного. Требует ввода названия для подтверждения (confirm-by-name). После
  удаления активным становится первое доступное пространство и происходит переход
  на «Главную». `DELETE /workspaces/:id`.

## 0.53.1 — 2026-07-16
- **Уход на «Главную» при удалении/переносе открытого проекта** — паритет с web
  0.134.3. Тот, кто удаляет или переносит проект, у которого открыта доска, сразу
  уходит на «Главную». Плюс realtime-обработчик `project.deleted`: если проект
  удалили/перенесли с другого клиента, любой пользователь с открытой доской этого
  проекта тоже уходит на «Главную» — без всплывашки «Не найдено».

## 0.53.0 — 2026-07-16
- **Перенос проекта в другое пространство** — паритет с web. В контекст-меню проекта
  в дереве появился оранжевый пункт «Перенести в другое пространство» (warning, не
  красный): открывает модалку выбора целевого пространства с предупреждением (проект
  переезжает со всеми досками/задачами/тегами/заметками, окажется без группы,
  не-члены снимаются с задач). После переноса — тост «снято исполнителей: N» и уход
  на «Главную», если была открыта доска этого проекта. `POST /projects/:id/transfer`.

## 0.52.2 — 2026-07-16
- **Антифлуд тостов активности при синке** — паритет с web 0.133.0. Во время всплеска
  событий (например, GitLab-синк создаёт/двигает много задач) индивидуальные тосты
  «кто что сделал» подавляются (>5 событий за 4с) — доска всё равно обновляется по
  дебаунс-пути. Пустые состояния экранов уже присутствуют.

## 0.52.1 — 2026-07-16
- **Перераспределение ширины колонок канбана** — паритет с web. Когда колонки свёрнуты
  в полоски, освободившаяся ширина теперь делится между раскрытыми колонками (они
  становятся шире), с потолком по размеру карточки. Без свёрнутых — прежняя мобильная
  ширина «одна колонка + подгляд следующей».

## 0.52.0 — 2026-07-16
- **Архив как полноценная readonly-доска** — паритет с web. Вместо плоского списка в
  модалке архив теперь открывается как режим доски: архивные задачи рендерятся через
  обычные представления (канбан/список/…) со всеми фильтрами, группировкой и
  сортировкой, но только для чтения (без DnD, создания задач/колонок, inline-правок и
  редакторов пиллов). Сверху — баннер «Архив (только чтение)» с кнопкой «Выйти»; на
  карточке меню даёт «Вернуть из архива» и «Удалить навсегда». Загрузка через
  `GET /boards/:id/tasks?archived=1`.

## 0.51.1 — 2026-07-16
- **Дедуп исполнителей GitLab** в пикере задачи — паритет с web. GitLab-участник,
  уже связанный с Tessera-аккаунтом (`tessera_user_id`), показывается один раз как
  Tessera-исполнитель с бейджем «GL» и убирается из списка «GitLab» (раньше двоился).

## 0.51.0 — 2026-07-16
- **Навигация по спринтам (серверный milestone-scope)** — паритет с web. На досках с
  этапами под тулбаром появилась панель «Спринт: …» с выбором «Все задачи» / «Бэклог» /
  конкретный этап; выбор перезапрашивает задачи доски со стороны сервера
  (`GET /boards/:id/tasks?milestone=<uuid|backlog>`) — важно для больших импортов
  из GitLab. Активный скоуп помечается акцентным чипом с крестиком для сброса. Прежний
  клиентский фильтр по этапу (deep-link из «Этапов») сохранён без изменений.

## 0.50.0 — 2026-07-16
- **Мультипривязка GitLab (GL-проект → доска)** — паритет с web + фикс. Экран
  «GitLab» теперь показывает список привязок пространства; админ может добавлять/
  редактировать/удалять привязки, участник — запускать синхронизацию каждой. В
  редактор добавлены поля «Название», «Область импорта» (назначенные мне / все) и
  «Закрытые задачи» (all / архив закрытых спринтов / период). Клиент переведён на
  ручки `GET/POST/PUT/DELETE …/gitlab/integrations[/:id]` и
  `POST …/integrations/:id/sync` (старые singular-ручки `/gitlab/integration` и
  `/gitlab/sync` бэкенд удалил ещё в be 0.71 — прежняя версия ловила 404).

## 0.49.0 — 2026-07-16
- **Админ-настройка GitLab OAuth** в панели «Администрирование» — паритет с web.
  Свёртываемая карточка «Вход через GitLab (OAuth)» (`GET/PUT /admin/oauth/gitlab`):
  GitLab URL, Client ID, Client Secret (write-only, пусто = не менять), инстанс-широкий
  сервис-токен (write-only), тумблер «включён», редактор `org_map` (JSON), и подсказка
  с Callback URL для OAuth-приложения GitLab. Все ручки перепроверяют admin на сервере.

## 0.48.0 — 2026-07-16
- **Вход через GitLab (OAuth)** — паритет с web. На экране входа при включённом на
  сервере провайдере появляется кнопка «Войти через GitLab»: она открывает
  Chrome Custom Tab с `…/api/auth/gitlab/authorize?platform=android`; после подтверждения
  бэкенд возвращает сессию через deep-link `tessera://oauth/callback#access_token=…`,
  который перехватывает `MainActivity` и передаёт токены в `AppRoot` → приложение сразу
  логинится. Секрет OAuth-приложения остаётся на сервере (confidential-app). Ошибки OAuth
  (`#oauth_error=…`) показываются на экране входа человекочитаемым сообщением.
  Требует бэкенд be ≥ 0.77.1 (мобильная ветка редиректа). Добавлена зависимость
  `androidx.browser` (Custom Tabs) и intent-filter `tessera://oauth` в манифесте.

## 0.47.0 — 2026-07-09
- **Стек полей — полный паритет с web `.pills.stacked`** (доводка по фидбэку):
  - **Инлайн-пикеры**: тап по строке поля в стеке открывает тот же пикер, что и у пилла
    (приоритет / срок / теги / исполнитель), а не проваливается в модалку.
  - **Теги — цветными чипами** как в модалке: сколько влезает по ширине карточки, столько
    и рисуется, остальное — чип «+N» (кастомный `TagChipsFit`-layout, web tag-fit).
  - **Срок — с заглавной буквы** и без пилла (просто «Сегодня»/«Завтра»/день недели/дата).
  - **Автор/исполнитель — аватарками** вместо текста (тот же оверлап-стек, что в инлайне).
  - Больше вертикальный интервал между строками стека — надёжнее тап по полю.
- **Чекбокс «Выполнено» перенесён в быстрые действия** рядом с «Создать подзадачу»
  (web hover-бар): на обычных карточках верхнего уровня галочка теперь в правой группе
  действий, а не ведущей; на подзадачах/компактных остаётся ведущей. Мета-строка (#номер)
  выровнена по левому краю, когда ведущей галочки нет.

## 0.45.0 — 2026-07-09
- **Иконка и цвет доски** — паритет web 0.119.0/0.121.0 (backend mig 0040). У доски,
  как у проектов/групп, теперь своя иконка + цвет + режим (бейдж/глиф):

## 0.44.0 — 2026-07-09

## 0.43.0 — 2026-07-09
- **Свёртка колонок канбана** — паритет web 0.118.0. Колонку можно свернуть в узкую
  44dp-полосу (чеврон в шапке): показывает повёрнутый вертикальный заголовок + счётчик,
  тап по полосе разворачивает обратно. Карточку по-прежнему можно бросить на свёрнутую

- **Иконка review-колонки** — паритет web 0.123.1: колонка, чьё имя совпадает с
  `рассмотр|ревью|review|проверк`, показывает ⅔-pie глиф `status_review` вместо
  «в работе» (contrast). Новый bundled-ассет `assets/ionicons/status_review.svg`.
